{%- comment -%} Links an episode to the topic hubs it belongs to, using the same title matching as the hub pages themselves (see _data/topics.yml). This is what connects the archive together: without it the hubs are only reachable from the nav, and every episode page is a dead end apart from its two neighbours. Expects `include.post`. {%- endcomment -%} {%- assign post_title_lc = include.post.title | downcase -%} {%- assign matched_topic_count = 0 -%} {%- capture matched_topic_links -%} {%- for topic in site.data.topics -%} {%- assign is_match = false -%} {%- for keyword in topic.keywords -%} {%- if post_title_lc contains keyword -%} {%- assign is_match = true -%} {%- break -%} {%- endif -%} {%- endfor -%} {%- if is_match -%} {%- assign matched_topic_count = matched_topic_count | plus: 1 -%}
  • {{ topic.title }}
    • {%- endif -%} {%- endfor -%} {%- endcapture -%}
    {%- if matched_topic_count > 0 %} More episodes about
      {{ matched_topic_links }}
    {%- else %} Find more episodes
    • Browse all topics
    {%- endif %}
